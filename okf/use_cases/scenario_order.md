# 生鮮品AI自動発注未反映 (#11403)

## 障害概要
特売マスタ更新時のJANコード桁数不備により、当日の生鮮品（青果・鮮魚・精肉）の自動発注データが基幹システムおよび卸売EDIに反映されずバッチが中断した障害。

## 推奨一次対応
1. OrderHub管理コンソールにてエラー対象レコードを一時保留（スキップ）に設定
2. 差分再送ジョブ『job-order-resync-fresh』を手動再実行する
