# 検品ハンディWi-Fi切断 (#11980)

## 障害概要
店舗バックヤードでネットワークスイッチ（`SW-BY-01`）の電源供給トラブルにより無線APがリンクダウンし、検品ハンディターミナルや業務用タブレットがオフラインとなる障害。

## 推奨一次対応
1. バックヤード通信ラック内のネットワークスイッチ（SW-BY-01）の電源ケーブルを抜く
2. 15秒待機後に再投入し、約3分後に無線APのLEDが緑点灯することを確認する
